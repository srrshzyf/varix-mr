# 静脉曲张 MR 训练原型 · 独立部署说明

这个文件夹就是完整的网页（index.html + 3 个脚本），不需要安装任何东西。

## 为什么需要独立部署
在 claude.ai 链接里打开时，页面在一个受限的框架中运行，头显浏览器很可能不允许进入 MR/VR 沉浸模式（只能以平面网页方式使用）。把这个文件夹放到任意 HTTPS 网址下，PICO 浏览器就可以进入 MR 透视模式。

## 三种部署方式（任选其一）
1. **学校/医院服务器**：把整个文件夹拷到任意 HTTPS 站点目录下，用头显打开 `https://…/varix-mr/index.html`。
2. **GitHub Pages**：新建仓库，上传这 4 个文件，在 Settings → Pages 选择 main 分支，得到 `https://用户名.github.io/仓库名/`。
3. **Netlify Drop**：浏览器打开 app.netlify.com/drop，把整个文件夹拖进去，得到一个 https 网址。

注意：必须是 https 地址（WebXR 的要求）；直接双击本地文件打开，电脑上可以预览，但头显进不了 MR。

## 在 PICO 4 Ultra 上打开
1. 头显戴好，打开“浏览器”应用。
2. 在地址栏输入部署后的网址（建议先在电脑上生成二维码或用书签同步，避免在头显里打长网址）。
3. 页面加载后点顶栏“进入 MR（透视）”，浏览器询问权限时选“允许”。
4. 进入后：面板在左前方，患者站在右前方。用手柄射线指向按钮、扣扳机确认；也可以捏合手指。
5. 按手柄的 Home/菜单键可退出沉浸模式。

## 两种场景
- 虚拟诊室（默认）：门诊诊室场景，患者推门进来、坐下问诊、站立查体、躺上检查床做超声，超声仪屏幕同步显示图像。适合用“进入 VR”。
- MR 透视：不显示诊室，保留真实环境，适合用“进入 MR（透视）”。顶栏或首页可切换。

## 3D 模型说明
- 病人：由 MakeHuman 开源人体基础网格（CC0 许可，可自由使用）按“54 岁、女性、东亚、体重略高、身高 158 cm”生成，带骨骼和面部表情（眨眼、张口、微笑、皱眉），皮肤、头发、衣物贴图为程序生成。生成脚本在 tools/patient/。
- 下肢解剖：皮肤直接使用同一人体的腿部网格，血管、神经、骨骼按真实腿表面重新贴合；左腿曲张属支隆起、内踝上方色素沉着、踝部静脉扩张冠烘焙进皮肤贴图与网格。解剖关系按教材绘制，属教学示意，不是真实患者影像重建。
- 手术器械：参照节段式射频消融系统的一般外观（7F 导管、7 cm 加热段、导管体每 6.5 cm 刻度、射频发生器、21G 微穿刺针、0.018 英寸导丝、7F 鞘管、静脉钩等），不含任何厂商商标。
- “解剖导览”模块可切换皮肤（实体/透明/隐藏）和浅静脉、穿通静脉、深静脉、动脉、神经、骨骼、隐筋膜图层，点选结构查看说明。

## 大模型对话
- 独立部署时，点“设置”可填写兼容 OpenAI chat/completions 格式的接口地址、模型名和密钥（只保存在当前浏览器）。接口需要允许浏览器跨域（CORS），很多国内大模型接口需要经过本校的转发服务才能在网页里直接调用。
- 不填写时，自动使用预设脚本：头显里点问题卡，或在电脑上打字，患者按病例文档的标准回答作答。
- 在 claude.ai 链接中打开时，患者由 Claude 扮演，无需设置。
